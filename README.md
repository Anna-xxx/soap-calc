# Расчёт варки мыла

Калькулятор варки мыла на ядро по шаблону «Рассчёт варки»: рецепт, щёлочь и вода, омыление, высолка, готовое мыло, справочник и себестоимость.

Сайт — один файл `index.html`, без сборки и сервера. Рецепты сохраняются в браузере пользователя.

`src/` — исходники страницы (стили, разметка, скрипт, база масел), из которых собран `index.html`.
